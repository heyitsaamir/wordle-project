# Wordle

Remake of the wordle game!

## Rules

- Guess the secret 5-letter word.
- You have 6 attempts to guess the word.
- After each guess, each letter is marked to show how close your guess was:
  - **Green**: the letter is in the word and in the correct spot.
  - **Yellow**: the letter is in the word but in the wrong spot.
  - **Gray**: the letter is not in the word at all.
- Use the feedback from each guess to narrow down the word.
- You win if you guess the word within 6 tries!
